# System & Sensor Monitor

A lightweight telemetry logger and dashboard for monitoring system performance and sensor inputs.

---

## Overview
This project tracks metrics (CPU/RAM or live sensor data) and logs timestamps for real-time analysis.

---

## Hardware / Requirements
- Python 3.x
- Dependencies: `psutil` (or `pyserial` for hardware)
